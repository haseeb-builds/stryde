# Stryde Product Truth

## What Stryde is
Stryde is a persistent situational-intelligence workspace that helps a person understand messy situations, make decisions, move work forward, execute authorized actions, verify what actually happened, and update durable state.

Core loop:

REALITY → SITUATION → UNKNOWN / BOTTLENECK → RECOMMENDATION → AUTHORITY → ACTION → EXECUTION → EVIDENCE → VERIFICATION → STATE UPDATE → NEXT ACTION

## Product principles
- Stryde absorbs ambiguity instead of turning it into a questionnaire.
- Conversation is working interaction and history, not canonical memory.
- Durable state is evidence-graded and provenance-aware.
- UNKNOWN is valid state.
- Action is not outcome.
- Mechanical success is not real-world verification.
- Models propose; deterministic control authorizes and enforces.
- Human authority remains over consequential decisions.
- Continuity across sessions is a core capability.
- Stryde should eventually perform bounded real work, not remain advice-only.

## V1 boundary
V1 prioritizes persistent Pursuits, adaptive conversation, canonical situation assembly, bounded reasoning, explicit authorization, one real controlled execution path, evidence capture, and deterministic verification.

Proactive monitoring, broad integrations, vector memory, multi-agent runtime, organization tenancy, and self-improvement are later capabilities.
