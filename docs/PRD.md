# Stryde Product Requirements — Historical Product Contract

Status: superseded as current-state authority by docs/PRODUCT.md
Use docs/PRODUCT.md for current product truth and docs/STATE.md for current implementation/runtime reality.

This document is retained to preserve prior product decisions.

Stryde is a persistent situational-intelligence workspace that helps a person understand messy situations, make decisions, move work forward, execute authorized actions, verify what actually happened, and update durable state.

Core intended loop:

REALITY → SITUATION → UNKNOWN / BOTTLENECK → RECOMMENDATION → AUTHORITY → ACTION → EXECUTION → EVIDENCE → VERIFICATION → STATE UPDATE → NEXT ACTION

The product principles and V1 conceptual boundary recorded here remain historical intent. Actual implementation status must be read from docs/STATE.md and docs/VERIFICATION_MATRIX.md.

Notably, the repository now contains conversation persistence/streaming code and source/human-action structures that were described as future or incomplete in some earlier versions of this document. Those historical statements should not be used as current-state claims.
