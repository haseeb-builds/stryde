# Stryde Build Roadmap

Build in dependency order. Do not reopen architecture unless runtime evidence or new research exposes a material contradiction.

1. Prove the Gemini gateway and remove stale provider wiring.
2. Finish adaptive conversation as the primary workspace interaction, including true streaming and durable session/history behavior.
3. Make reasoning consume server-side persisted context rather than client-supplied transcript truth.
4. Bridge reasoning proposals into deterministic Action/Decision/Claim mutations without model authority.
5. Complete one genuine HUMAN action path and one genuine CONTROLLED action path.
6. Run Action → Job → Attempt through the existing execution control plane.
7. Capture mechanical evidence as Observation and close the loop with verification.
8. Enforce VERIFIED only through deterministic predicates/evidence.
9. Build focused evals and failure-injection tests around hallucination, authorization, fencing, idempotency, UNKNOWN, lineage, and continuity.
10. Harden production behavior and only then perform the final premium workspace visual pass.
11. Expand integrations only when each one has a real use case, capability boundary, authorization policy, and verification story.

Done means runtime behavior plus evidence, not code presence or agent claims.
