# Stryde Product Brief — Stitch Context

## 1. Product Identity & Purpose
Stryde is a persistent personal pursuit system designed to move a meaningful intention into completed reality. It acts as an evidence-aware operational partner for complex, multi-week personal and professional objectives (e.g. launching a product, auditing an infrastructure migration, negotiating contracts, or executing a high-stakes fitness regime).

It is explicitly **not** a chatbot, a task manager with an AI wrapper, a generic SaaS dashboard, or a collection of disconnected AI prompt templates.

## 2. The Core Operational Loop
Every interaction in Stryde is governed by a unified loop:
```
User Intention
  → Reconstruct Current Situation
  → Identify the Actual Bottleneck
  → Acquire Appropriate Evidence
  → Propose the Single Next Meaningful Move
  → Authorize, Guide, or Execute the Move
  → Observe What Actually Happened
  → Verify Outcomes Against Evidence
  → Update Persistent Memory & Pursuit State
  → Choose Next Move
```

## 3. Product Personality & Editorial Tone
- **Tone:** Calm, precise, evidence-conscious, uncluttered, and direct.
- **Epistemic Discipline:** Clear distinction between what is known, what is inferred, what the user self-reported, and what is independently verified.
- **No Progress Hallucination:** Stryde never pretends work has been done, never marks an outcome as verified without evidence, and never claims a queued background worker has finished.
- **Universal Control Surface:** A single universal composer at the base of the pursuit allows the user to bring reality (goals, questions, pasted notes, action reports, file uploads, corrections) without having to navigate fragmented modes or manage workflows.

## 4. Key Target Audiences
- Founders, engineers, and solo operators navigating ambiguous multi-step outcomes.
- Researchers and strategists needing strict source provenance and verification tracking.
- Busy professionals who resume pursuits after days of absence and need immediate, unambiguous orientation on *what matters right now*.
